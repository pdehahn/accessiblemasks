AccessibleMasks.org

AccessibleMasks.org was an online resource built to address the challenge solid face masks presented to deaf and hard of hearing communities, as well as for elderly people or those speaking other languages and needing facial cues.

This repository was created to host an archive of AccessibleMasks.org, which is no longer being updated and maintained. 

The following tools were used to complete the archive: 
Publii
GitHub
Porkbun
GitHub Pages
